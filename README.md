# Underground Agency — portfolio site

Standalone static website prepared for publication through GitHub Pages. This directory is intentionally isolated from the existing personal `portfolio` repository and from VITEAL's brand assets.

## Preview

Open `index.html` in a browser or serve this directory with any static HTTP server.

## Publish

The site is buildless: publish the repository root with GitHub Pages. The Quantus case study PDF is in `assets/quantus-case-study.pdf` and is linked from the case section.
